# 🍳 KinRaiDee

AI-powered Kitchen Operating System

## Vision

Help everyone answer one simple question:

> วันนี้กินอะไรดี?

using AI.

---

## Features

- Pantry Management
- Pantry Insights
- Recipe Readiness
- Pantry-based Purchase Recommendations
- Shopping and Pantry Merge
- Cooking History

Planned features include Smart Shopping Optimization, Ingredient Substitution,
and an AI Cooking Advisor.

---

## Tech Stack

- Flutter
- Riverpod
- Hive
- GoRouter
